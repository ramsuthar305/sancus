What that means

Per core, Sancus does about a seventh of APISIX and half of KrakenD. That is the cost of running on a JavaScript HTTP stack. Per request Sancus spends about 47 microseconds of CPU. APISIX spends about 12.

One Sancus process handles about 21,000 requests a second on a laptop. A pod with four workers handles 30,000 to 37,000. Most products peak well below 5,000, where one or two small pods cover it and the gateway is nowhere near the bottleneck. At that load the extra latency is about 0.3 milliseconds at the median.

If your edge does 50,000 requests a second per node, pick APISIX or Kong. If your team's time is the scarce thing, the per-feature table below is what you pay for each convenience.

Where the time goes

To find out what to fix, four proxies were measured against the same upstream. All of Sancus's own logic, meaning matching, auth, limits, cache, policies and metrics, cost six percent. The http-proxy library cost 42 percent. Express cost 35 percent.

Stackreq/sCPU per request
Raw Node request pipe, no framework42,10024 µs
http-proxy library alone24,20041 µs
Express plus http-proxy, no gateway logic15,80063 µs
Sancus before the change14,90067 µs

So the library went. Sancus now pipes with http.request and keeps Express. Plain proxy went from 14,900 to 21,400 requests a second and p99 from 10.9 to 8.0 ms. The same run caught a bug: the upstream pool capped free sockets at 32, churned connections under load, and ran out of ports. That is fixed and every table above has zero errors.

Dropping Express would reach roughly 35,000 per process. Four workers already pass that, so it stays on the list.

Reproduce it

brew install wrk oha           # or apt / your package manager
npm ci && npm run build
npm run bench                  # per-feature, results in tests/bench/results/
docker build -t sancus:slim .
tests/bench/compare/compare.sh # Sancus vs Traefik, Kong, APISIX, KrakenD

Run it on a Linux box with dedicated cores and send a pull request with the numbers. The scripts print the exact commands and fail on any non-2xx response.
